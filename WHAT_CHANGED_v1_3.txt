DOG RACE GBGB v1.3 - SQLite DATABASE LOCK FIX (18 November 2026)

Symptom seen on Windows:
    requesting https://api.gbgb.org.uk/api/results?...
    GBGB: database is locked

Likely cause: the v1.2 GBGB module shares data/dog_race.sqlite3 with the
Australian collector, and SQLite cannot obtain its write lock. A concurrent
DB viewer or synced folder can also produce this error. Exact cause on the
user PC cannot be proven from the screenshot alone.

Fixes:
1. All GBGB writes now use data/gbgb.sqlite3 (NEW dedicated database).
2. Australian/shared data/dog_race.sqlite3 is untouched.
3. Previously downloaded raw JSON is automatically reused when the run resumes.
4. 45-second SQLite busy timeout; WAL mode; database connection closed on exit.
5. OS-level single-job lock stops two GBGB bulk jobs running together.
6. Clearer diagnostic output on SQLite lock failures.
